# Kenya Intel Hub

Build a modern, high-performance web application called ZERO, an advanced campaign intelligence and digital risk monitoring platform with a sleek dark UI similar to a premium cyber intelligence dashboard with neon purple and blue accents, glassmorphism cards, real-time charts, and a global data visualization map. The system must follow an iterative, modular architecture and include both a user-facing dashboard and a powerful admin control panel. The core platform should aggregate data from multiple compliant APIs including social media, news, and OSINT sources, process large-scale structured and unstructured data in real time, and use AI to generate insights, sentiment analysis, narrative detection, competitor comparisons, and predictive trends. The main dashboard should include widgets such as mentions analyzed, threat score, narratives detected, influence reach, and data sources, along with a live intelligence feed, sentiment overview, top narratives, competitor analysis, and AI-generated insight summaries. Include modular bots: Recon Bot for public data aggregation, Vulnerability Bot for exposure and risk detection, Identity Bot for cross-platform identity correlation, Threat Intelligence Bot for risk scoring and anomaly detection, Brand Protection Bot for impersonation and reputation monitoring, and Deep Dive Bot that combines all modules into comprehensive reports. Add features for real-time alerts, report generation, press briefing creation, and narrative strategy suggestions. Integrate a compliant dark web monitoring module that only detects leaks, breaches, or exposed credentials via legal data providers without any unauthorized access. The system must include a powerful AI assistant for generating reports, speeches, and campaign messaging based on analyzed data. Build a full admin panel with role-based access control where admins can manage users, configure APIs (input keys, set rate limits, toggle sources), control modules, adjust AI behavior, manage system settings, monitor logs, and view analytics on system usage. Include authentication, user roles (admin, analyst, viewer), billing integration, and activity tracking. Use a scalable backend (Node.js or Python), real-time database, and clean API architecture, with responsive frontend design optimized for desktop and mobile. Ensure the UI is visually stunning, fast, and intuitive, with smooth animations and a premium feel, making ZERO look like an award-winning intelligence-grade platform.
